# TrustFolio

🌟 **Plateforme de création de livres personnalisés pour enfants**

TrustFolio est une application Next.js qui permet aux parents de créer des livres personnalisés pour leurs enfants, avec des histoires adaptées à leurs valeurs et leur culture.

## 🚀 Démarrage rapide

```bash
# Installation des dépendances
npm install

# Configuration de la base de données PostgreSQL
# Voir docs/POSTGRESQL_SETUP.md pour les instructions détaillées

# Lancement du serveur de développement
npm run dev
```

L'application sera disponible sur [http://localhost:3000](http://localhost:3000)

## ✨ Fonctionnalités principales

- 📖 Création de livres personnalisés
- 🎨 Interface utilisateur moderne et responsive
- 🌍 Support multilingue (FR, EN, DE, ES, AR)
- 💳 Système de paiement intégré
- 📱 Intégration WhatsApp
- 🔐 Authentification utilisateur
- 📊 Base de données PostgreSQL avec Drizzle ORM

## 🛠️ Technologies utilisées

- **Frontend** : Next.js 14, React, TypeScript, Tailwind CSS
- **Backend** : Next.js API Routes, NextAuth.js
- **Base de données** : PostgreSQL avec Drizzle ORM
- **Authentification** : NextAuth.js
- **Styling** : Tailwind CSS, Framer Motion
- **Intégrations** : WhatsApp Web.js
