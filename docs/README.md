Pour contribuer à la documentation :

2. Créer une branche `docs/feature-name`
3. Modifier la documentation appropriée

5. Créer une pull request

### Standards de Contribution

- **Clarté** : Explications simples et directes
- **Exemples** : Code examples fonctionnels
- **Liens** : Références croisées entre documents
- **Mise à jour** : Synchronisation avec les changements de code
